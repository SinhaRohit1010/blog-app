# 2. Scope & Objectives

## 2.1 Purpose
The purpose of this project is to develop a **Blog Management Application** that allows administrators to create and manage blog content while enabling users to read, comment, and subscribe for blog updates.  
The system promotes simplicity, engagement, and efficient communication between admins and readers.

---

## 2.2 Scope

**A. User-Facing Features**
- View all published blogs and filter by category.  
- Read detailed blog pages (title, author, date, thumbnail, description).  
- Post comments (pending admin approval).  
- Subscribe globally to receive email notifications for new blogs.  

**B. Admin-Facing Features**
- Secure login system for administrators.  
- Create, edit, publish, and delete blogs.  
- Moderate user comments (approve/reject).  
- View and manage subscribed users.  
- Automatic email notifications sent when new blogs are published.  
- Dashboard analytics showing total blogs, comments, drafts, and subscribed users.

---

## 2.3 Objectives

| Objective | Description | Success Indicator |
|------------|--------------|-------------------|
| **Simplify Blog Management** | Provide a clean dashboard for creating and managing blogs. | Admin can publish or edit blogs easily. |
| **Enhance Reader Engagement** | Allow readers to comment and subscribe to updates. | Increase in active readers and subscriptions. |
| **Automate Communication** | Automatically notify users about new blogs. | Successful automated email delivery via SES. |
| **Centralized Control** | Manage blogs, comments, and subscriptions in one place. | Single dashboard managing all key operations. |

# 5. Functional Requirements

## FRD-001: Blog Management
- **Description:** Admin can create, edit, publish, or delete blogs.  
- **Priority:** Must-have  
- **Actor:** Admin  
- **Use Case:** “As an Admin, I want to publish new blogs for readers.”  

## FRD-002: Comment Management
- **Description:** Users can post comments; Admins can approve or reject them.  
- **Priority:** Must-have  
- **Actors:** User, Admin  

## FRD-003: Email Preference Subscription
- **Description:** Users can subscribe or unsubscribe globally to receive blog update emails.  
- **Priority:** Must-have  
- **Actor:** User  

## FRD-004: Admin Dashboard
- **Description:** Admin can view total blogs, comments, and subscribed users.  
- **Priority:** Must-have  

## FRD-005: Authentication and Authorization
- **Description:** Secure admin login with restricted access.  
- **Priority:** Must-have
